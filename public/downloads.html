Technical API JSON Schemas & Validation Rules

Software developers, ERP vendors, and ASP/GSPs can download official GST JSON schemas to ensure client-side payload validation matches statutory GST common portal requirements.

Validates B2B, B2C, EXP, CDNR, HSN, and Document Summary records.

Validates monthly summary outward supplies, eligible ITC, exempt inward, and Rule 88A tax payments.
